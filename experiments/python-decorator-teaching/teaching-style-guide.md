# 技术教学系列 - 视觉风格规范

> 本文件定义系列教学 HTML 页面的统一视觉风格，所有期数必须遵循。

---

## 风格定位：「技术手札」风

介于严肃教材和随性博客之间。像一位有经验的同事在白板上给你画图讲解——有结构、有温度、有手感。

---

## 色彩体系

### 主色调

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面背景 | `#FAFAF9` | 暖白，减少屏幕疲劳 |
| 正文文字 | `#1A1A1A` | 近黑，保证可读性 |
| 主强调色 | `#6366F1` | Indigo，用于标题、关键概念高亮 |
| 辅助强调 | `#EC4899` | Pink，用于注意事项、陷阱提示 |
| 代码背景 | `#1E1E2E` | 深色（Catppuccin Mocha 风格） |
| 代码文字 | `#CDD6F4` | 浅灰蓝 |
| 成功/正确 | `#10B981` | Emerald |
| 警告/注意 | `#F59E0B` | Amber |
| 卡片背景 | `#FFFFFF` | 纯白，配合阴影浮起 |
| 分隔/边框 | `#E5E5E4` | 浅灰 |

### 代码高亮配色（基于 Catppuccin Mocha）

| Token 类型 | 色值 |
|------------|------|
| 关键字 | `#CBA6F7`（Mauve） |
| 字符串 | `#A6E3A1`（Green） |
| 函数名 | `#89B4FA`（Blue） |
| 注释 | `#6C7086`（Overlay0） |
| 装饰器 @ | `#F9E2AF`（Yellow） |
| 参数 | `#FAB387`（Peach） |
| 数字 | `#F38BA8`（Red） |

## 排版规范

### 字体

```css
--font-body: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
--font-code: 'JetBrains Mono', 'Fira Code', 'SF Mono', monospace;
--font-heading: 'Inter', sans-serif;
```

### 字号

| 元素 | 大小 | 行高 |
|------|------|------|
| 页面标题 | 2.5rem | 1.2 |
| 章节标题 | 1.75rem | 1.3 |
| 小节标题 | 1.25rem | 1.4 |
| 正文 | 1rem (16px) | 1.75 |
| 代码 | 0.875rem | 1.6 |
| 注释/标注 | 0.875rem | 1.5 |

### 间距

- 章节之间：`4rem`
- 段落之间：`1.5rem`
- 代码块上下：`2rem`
- 页面最大宽度：`860px`
- 页面左右 padding：`2rem`

## 组件规范

### 1. 代码块

- 深色背景 + 圆角（`border-radius: 12px`）
- 左上角显示语言标签（小字，半透明）
- 代码行号可选（复杂示例开启）
- 关键行可高亮（背景加深 `rgba(255,255,255,0.05)`）
- 支持行内注释气泡（指向特定行的解释）

### 2. 概念卡片

- 白色背景 + 微阴影（`box-shadow: 0 2px 12px rgba(0,0,0,0.06)`）
- 左侧彩色边条（4px，颜色对应类型）
- 圆角 `12px`
- 内边距 `1.5rem`

### 3. 比喻/类比区块

- 浅紫色背景（`#EEF2FF`）
- 左侧带灯泡图标 💡
- 用于将抽象概念映射到日常经验

### 4. 陷阱/警告区块

- 浅红色背景（`#FEF2F2`）
- 左侧带警告图标 ⚠️
- 用于常见错误和易混淆点

### 5. 流程图/示意图

- 使用 CSS + HTML 绘制（不依赖外部图片）
- 箭头用 SVG 或 CSS border 实现
- 节点用圆角矩形，配合主色调

### 6. 交互式代码演示（可选）

- 代码区域可折叠/展开
- "等价于"对比：左右并排或上下对照
- 执行流程用步骤动画（CSS transition）

## 页面结构模板

```

│  页面标题 + 副标题 + 期数标识        │
│  （居中，主色调渐变背景）            │
├─────────────────────────────────────┤
│  目录导航（可选，内容多时启用）      │
├─────────────────────────────────────┤
│  章节 1                              │
│    - 概念讲解                        │
│    - 代码示例                        │
│    - 类比/图示                       │
├─────────────────────────────────────┤
│  章节 2 ...                          │
├─────────────────────────────────────┤
│  本期总结（要点回顾卡片）            │
├─────────────────────────────────────┤
│  页脚（系列信息 + 下期预告）         │
└─────────────────────────────────────┘
```

---

## 动效规范

- 页面加载：章节依次淡入（`fadeInUp`，间隔 100ms）
- 代码块：hover 时微微上浮（`translateY(-2px)`）
- 滚动：章节标题进入视口时触发淡入
- 不使用过度动画，保持专业感

---

## 响应式

- 移动端（< 768px）：单栏，代码块可横向滚动
- 平板（768px - 1024px）：保持单栏，间距适当缩小
- 桌面（> 1024px）：居中显示，最大宽度 860px

---

## 命名约定

- 文件名格式：`python-{主题}-ep{期数}.html`
- 示例：`python-decorator-ep01.html`、`python-generator-ep01.html`

---

## 注意事项

1. 所有页面必须是单文件 HTML（内联 CSS + JS），不依赖外部资源
2. 字体使用系统字体栈 fallback，不强制加载 Google Fonts（可用 CDN 作为增强）
3. 代码高亮手动实现（用 `<span>` + class），不依赖 highlight.js 等库
4. 页面在无 JS 环境下仍可正常阅读（JS 仅用于增强动效）
