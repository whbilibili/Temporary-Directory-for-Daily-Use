组件规范

1. 代码块
  • 深色背景 + 圆角（border-radius: 12px）
  • 左上角显示语言标签（小字，半透明）
  • 代码行号可选（复杂示例开启）
  • 关键行可高亮（背景加深 rgba(255,255,255,0.05)）
  • 支持行内注释气泡（指向特定行的解释）
实际效果预览
Python 
def hello(name):
    # 这是一行注释
    return f"Hello, {name}!"
2. 概念卡片
  • 白色背景 + 微阴影（box-shadow: 0 2px 12px rgba(0,0,0,0.06)）
  • 左侧彩色边条（4px，颜色对应类型）
  • 圆角 12px
  • 内边距 1.5rem
实际效果预览

默认卡片：左侧 Indigo 边条，用于核心概念。

Pink 卡片：用于注意事项和陷阱提示。

Success 卡片：用于正确做法和最佳实践。

Warning 卡片：用于需要注意但非错误的提醒。

3. 比喻/类比区块
  • 浅紫色背景（#EEF2FF）
  • 左侧带灯泡图标 💡
  • 用于将抽象概念映射到日常经验
实际效果预览
💡

类比示例：闭包就像一个背包，内层函数离开外层函数时，把需要的变量装进背包带走了。

4. 陷阱/警告区块
  • 浅红色背景（#FEF2F2）
  • 左侧带警告图标 ⚠️
  • 用于常见错误和易混淆点
实际效果预览
⚠️

陷阱示例：带参装饰器忘加括号会导致参数错位，这是最常见的装饰器 Bug。

动效规范

触发场景动效说明
页面加载 fadeInUp 章节依次淡入，间隔 100ms
代码块 hover translateY(-2px) 微微上浮，增加层次感
滚动进入视口 淡入 章节标题进入视口时触发
⚠️

原则：不使用过度动画，保持专业感。动效是锦上添花，不是主角。

响应式

断点布局策略
移动端 < 768px 单栏，代码块可横向滚动
平板 768px - 1024px 保持单栏，间距适当缩小
桌面 > 1024px 居中显示，最大宽度 860px

命名约定与注意事项

文件命名

格式：python-{主题}-ep{期数}.html

示例：python-decorator-ep01.html、python-generator-ep01.html

注意事项

#规则
1 所有页面必须是单文件 HTML（内联 CSS + JS），不依赖外部资源
2 字体使用系统字体栈 fallback，不强制加载 Google Fonts（可用 CDN 作为增强）
3 代码高亮手动实现（用 <span> + class），不依赖 highlight.js 等库
4 页面在无 JS 环境下仍可正常阅读（JS 仅用于增强动效）
