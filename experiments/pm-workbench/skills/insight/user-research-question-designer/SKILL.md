# User Research Question Designer — 用研问题设计工具

**核心原则：** 问用户做了什么，而不是他们会做什么。行为 > 态度 > 意图。

## 用研问题的5种致命错误

| 错误类型 | 错误示例 | 正确版本 |
|---|---|---|
| **引导性问题** | "你觉得我们的AI功能好用吗？" | "告诉我你上次用AI助手时发生了什么？" |
| **假设性问题** | "如果我们加了X功能，你会用吗？" | "你现在用什么方式解决这个问题？" |
| **双重问题** | "你觉得产品好用且价格合理吗？" | 拆成两个独立问题 |
| **封闭问题（开场）** | "你喜欢这个功能吗？"（是/否） | "说说你用这个功能的经历？" |
| **专业术语** | "你的DAU感知如何？" | "你每天大概用多少次？" |

## 三种研究目的的问题框架

### 目的A：发现问题（探索式）
适用于：不知道用户痛点在哪，需要开放式探索

**问题模板：**
- "告诉我你最近一次[目标行为]是什么时候，发生了什么？"
- "在[使用场景]时，什么事情让你最费劲？"
- "如果你可以改变[产品/流程]的一件事，是什么？"
- "你通常在什么情况下会[目标行为]？"
- "从头讲一下你[完成某任务]的整个过程？"

### 目的B：验证假设（验证式）
适用于：已有假设，需要确认或否定

**框架：** 先观察行为，再确认认知，最后探索动机
- "你上次[和假设相关的行为]是什么时候？"
- "那次你是怎么处理的？"
- "你当时为什么选择这个方式，而不是[其他方式]？"
- "如果[假设条件成立]，你当时会怎么做不同的？"

### 目的C：需求挖掘（深挖式）
适用于：已知有问题，需要找到真实需求

**使用5个为什么：**
```
观察到的行为/问题
→ 为什么会这样？（行为原因）
  → 为什么会这样？（深层原因）
    → 为什么会这样？（更深层原因）
      → 为什么会这样？（根本原因）
        → 为什么会这样？（核心需求）
```

**挖掘深层需求的追问句式：**
- "你说[X]，能再讲详细一点吗？"
- "当时你是怎么想的？"
- "在那之前发生了什么？"
- "那对你意味着什么？"
- "如果这个问题消失了，对你有什么影响？"

## 工作流程

### Step 1：明确研究目标

询问用户：
1. 这次用研想回答什么核心问题？
2. 研究对象是哪类用户？
3. 研究方法是什么（深度访谈/问卷/观察）？
4. 有没有已经有的假设需要验证？

### Step 2：设计问题结构

**访谈问题的三段式结构：**
- **暖场（5分钟）**：建立信任，了解用户背景，不涉及核心问题
- **主体（30-40分钟）**：围绕核心问题展开，从行为到认知到动机
- **收尾（5分钟）**：给用户补充空间，询问"还有什么想说的？"

### Step 3：逐一检查问题质量

对每个问题，运行5项检查：
- [ ] 是否引导用户给出你想要的答案？
- [ ] 是否要求用户预测未来行为（而非描述过去行为）？
- [ ] 是否一个问题问了两件事？
- [ ] 是否使用了用户可能不理解的专业术语？
- [ ] 是否能用"是/否"回答（开场问题尤其要避免）？

### Step 4：输出问题大纲

```
## 📝 用研问题大纲

**研究目标：** [核心问题]
**研究对象：** [用户画像]
**研究方法：** [深度访谈/问卷/etc]
**预计时长：** [X分钟]

---

### 暖场问题（5分钟）

1. [背景问题，了解用户的基本情况]
2. [让用户放松的开放性问题]

### 核心问题（X分钟）

**[话题1]：**
3. [行为类问题——让用户描述过去发生的事]
4. [追问——深挖细节]
5. [动机类问题——问为什么]

**[话题2]：**
6. ...

### 收尾问题（5分钟）

X. "还有什么关于[话题]的事情，你觉得我没问到，但你想说的？"

---

### ⚠️ 注意事项

- [针对这次研究的特别提醒]
- [哪些话题需要格外注意引导性]
```
