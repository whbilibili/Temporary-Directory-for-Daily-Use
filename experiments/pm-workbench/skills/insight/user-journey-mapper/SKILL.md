# User Journey Mapper — 用户旅程与情绪曲线工具

**核心输出：** 一张完整的用户旅程，每个节点标注行为、想法、情绪，识别最值得优化的"情绪低谷"。

## 旅程分析的五个维度

每个旅程节点需要分析：
1. **行为（Doing）** — 用户在做什么？
2. **想法（Thinking）** — 用户在想什么？期望是什么？
3. **情绪（Feeling）** — 用户感受如何？（-5到+5评分）
4. **痛点（Pain）** — 遇到了什么障碍或负体验？
5. **机会（Opportunity）** — 可以如何优化？

## 工作流程

### Step 1：定义分析范围

询问用户：
1. 要分析哪个用户群体？
2. 要分析哪个核心任务/场景？（例："用户第一次下单外卖"）
3. 旅程的起点和终点分别是什么？

**提示：** 好的旅程范围不要太宽（"用户使用产品全程"太宽），也不要太窄（"用户点击支付按钮"太窄）。建议是一个完整的任务闭环。

### Step 2：拆解旅程阶段

将旅程分为3-6个大阶段（Phase），例如外卖场景：
- 发现需求 → 搜索/浏览 → 选择/决策 → 下单支付 → 等待配送 → 收货评价

每个阶段再拆成2-5个具体步骤（Step）。

### Step 3：逐步骤分析

对每个步骤，引导用户回答（或基于用研数据推断）：
- 用户做了什么动作？
- 用户的期望是什么？
- 实际得到了什么？
- 情绪评分是多少？（-5=极度挫败，0=中性，+5=非常愉悦）

**情绪评分参考：**
- +5：超出预期，会主动分享给他人
- +3：满意，没有负面感受
- +1：稍好，基本完成了任务
- 0：中性，无感
- -1：有点麻烦，但能接受
- -3：明显负体验，会影响下次使用意愿
- -5：极度挫败，会直接放弃或投诉

### Step 4：识别关键节点

基于情绪曲线，识别：

**🔴 情绪低谷（最值得修复）：**
- 情绪评分 < -2 的节点
- 这里是用户流失和投诉的主要来源

**⭐ 情绪高峰（要保护和放大）：**
- 情绪评分 > +3 的节点
- 这里是用户口碑和复购的来源，不能破坏它

**🔵 情绪断层（体验设计机会）：**
- 两个相邻步骤情绪分差距超过3分的地方
- 说明有突变体验，要么是设计缺失，要么是惊喜点

### 附：常见旅程分析误区

1. **只关注产品内旅程** — 用户旅程在进App之前就开始了（搜索、听说、下载），别只分析App内的步骤
2. **用平均用户代表所有用户** — 新用户和老用户的旅程差异可能很大，要分开分析
3. **把情绪低谷都当痛点要修** — 有些情绪低谷是任务本身的难度（如：填写复杂表单），不能完全消除，但可以用设计降低挫败感
4. **忽略"空白"旅程** — 用户在等待（等配送、等审核）时的体验也是旅程的一部分
