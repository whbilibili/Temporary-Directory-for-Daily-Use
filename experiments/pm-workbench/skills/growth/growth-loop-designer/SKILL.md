# Growth Loop Designer — 增长飞轮设计工具

**增长循环 vs 增长漏斗的核心区别：**
- 漏斗：线性，每次增长都需要重新投入（广告→用户，广告停→增长停）
- 飞轮：循环，用户的行为本身产生下一批用户，越转越快

## 四种增长循环类型

| 类型 | 原理 | 典型产品 |
|---|---|---|
| **病毒式循环** | 用户使用→邀请他人→更多用户使用 | Dropbox邀请送空间、微信红包 |
| **内容循环** | 用户创作内容→内容吸引新用户→更多创作者 | YouTube、小红书、抖音 |
| **付费循环** | 用户付费→更多收入→更好产品→更多用户 | Spotify Premium |
| **供给循环** | 更多买家→更多卖家→更多供给→更多买家 | 美团、淘宝、Airbnb |

## 工作流程

### Step 1：了解产品现状

询问：
1. 产品是什么？核心用户行为是什么？
2. 现在的新用户主要从哪里来？
3. 用户留下来的核心动力是什么？

### Step 2：识别已有循环

梳理产品中已有的循环元素：
- **输入**：什么触发了循环的开始？
- **核心行为**：循环中用户做了什么？
- **输出**：这个行为产生了什么？
- **再输入**：输出如何反哺新一轮循环的输入？

### Step 3：评估循环质量（5维打分）

| 维度 | 说明 | 1-5分 |
|---|---|---|
| **循环紧密度** | 从行为到下一个新用户，有几个步骤？步骤越少越好 | |
| **转化效率** | 每一步的转化率如何？有没有明显漏损 | |
| **循环速度** | 完成一个循环需要多长时间？越短越好 | |
| **可持续性** | 循环能持续转动吗？还是用完即止 | |
| **防御性** | 竞对能轻易复制这个循环吗？ | |

### Step 4：设计优化或新循环

如果现有循环不强，提供设计建议：
1. **缩短循环路径**：能否减少循环中的步骤？
2. **提升关键转化率**：哪个节点是最大漏损点？
3. **加速循环速度**：能否让用户更快完成核心行为？
4. **增加循环强度**：每次循环能带来多少新用户？

### Step 5：输出设计报告

```
## 🔄 增长循环设计报告

**产品：** [产品名]

### 已识别的增长循环

**主要循环（[类型]型）：**
[用户A] → [做了X行为] → [产生了Y] → [带来了新用户B] → 循环

循环质量评分：XX/25

**循环路径图（文字版）：**
① [触发] → ② [核心行为] → ③ [输出] → ④ [再输入] → ①

### 循环短板分析

| 步骤 | 当前状态 | 改进空间 |
|---|---|---|
| ① [触发] | [描述] | [建议] |
| ② [核心行为] | ... | ... |
| ③ [输出] | ... | ... |
| ④ [再输入] | ... | ... |

### 💡 增强循环的3个建议

1. [最高优先级建议]
2. [次优先级]
3. [第三建议]

### ⚠️ 注意事项

[指出循环中的风险：如"病毒式裂变容易引发骚扰投诉"、"供给侧循环启动需要先有买家基础"等]
```
