# kpi-tree-builder

**KPI树分解工具** — 将北极星指标逐层拆解到可执行的叶节点指标。

## 触发条件
用户提到：KPI分解、指标拆解、目标树、指标体系、北极星指标如何落地。

## 执行步骤

### Step 1：确认北极星指标
- 用户输入或提炼核心北极星指标（NSM）
- 确认业务背景（产品类型、阶段）

### Step 2：分解为L1指标（驱动因子）
将NSM分解为乘法公式或加法公式的组成部分：
- **乘法型**：`NSM = A × B × C`（如：GMV = 订单数 × 客单价）
- **加法型**：`NSM = A + B + C`（如：DAU = 新用户 + 回访用户）

### Step 3：继续拆解L2指标
每个L1指标再拆解为可测量的L2指标：
- L2指标必须可直接在数据系统中查到
- 标注每个L2指标的**可影响程度**（高/中/低）

### Step 4：输出KPI树
```
北极星指标
├── L1-A
│   ├── L2-A1（可影响度：高）
│   └── L2-A2（可影响度：中）
├── L1-B
│   ├── L2-B1（可影响度：高）
│   └── L2-B2（可影响度：低）
└── L1-C
    └── L2-C1（可影响度：中）
```

### Step 5：识别杠杆点
- 标出**高影响度 + 当前落后**的叶节点
- 这些是优先级最高的改善目标

## 输出格式
```
【KPI树】
北极星：[指标名称] 当前值：[X] 目标：[Y]

分解公式：NSM = [公式]

L1 驱动因子：
- [A]：当前[值] → 目标[值] | 影响权重：[%]
- [B]：当前[值] → 目标[值] | 影响权重：[%]

L2 可执行指标：
- [A1]（属于A）：当前[值] | 行业基准[值] | 可影响度：高 ⚡
- [A2]（属于A）：当前[值] | 行业基准[值] | 可影响度：中

🎯 优先杠杆点：[A1] — 落后行业基准[X]%，且高影响度
```

## 常见误区
- ❌ 指标树超过3层（执行距离太远）
- ❌ 叶节点指标不可直接测量
- ❌ 遗漏"互斥穷举"检查（各子指标不重叠、合计等于父指标）
