# product-health-dashboard

**产品健康度仪表盘** — 快速搭建多维产品健康监控体系，输出量化评分卡。

## 触发条件

用户提到：产品健康度、产品体检、产品状态、健康度评分、周报指标、月报模板、产品状态总览。

## 四大维度框架

### 1️⃣ 增长维度（Growth）
| 指标 | 说明 | 健康阈值 |
|---|---|---|
| DAU/MAU | 用户粘性 | >40% 良好 |
| 新用户占比 | 获客健康度 | 10-30% 健康 |
| QoQ/YoY 增长率 | 规模增长 | 正增长 |
| 渠道集中度 | 获客多样性 | 单渠道<50% |

### 2️⃣ 留存维度（Retention）
| 指标 | 说明 | 健康阈值 |
|---|---|---|
| 次日留存 | 初体验质量 | >40% |
| 7日留存 | 习惯养成 | >20% |
| 30日留存 | 产品价值锚 | >10% |
| 流失率 | 用户流失速度 | 月流失<10% |

### 3️⃣ 体验维度（Experience）
| 指标 | 说明 | 健康阈值 |
|---|---|---|
| NPS | 净推荐值 | >30 良好 |
| 核心任务完成率 | 功能可用性 | >85% |
| 页面报错率 | 稳定性 | <1% |
| 客诉率 | 体验质量 | <0.1% |

### 4️⃣ 商业维度（Revenue）
| 指标 | 说明 | 健康阈值 |
|---|---|---|
| ARPU | 用户价值 | 对标行业 |
| LTV/CAC | 投入产出比 | >3 健康 |
| 付费转化率 | 商业化效率 | 依赖产品类型 |
| 营收增长率 | 商业规模 | 正增长 |

## 执行步骤

### Step 1：收集指标数据
询问用户当前四大维度的关键指标数值（可只提供部分，其余标注"待补充"）。

### Step 2：计算健康度评分
每个维度 0-100 分：
- 指标达标数量 / 总指标数 × 100
- 有重大风险项（如留存率持续下降）直接降至60分以下

### Step 3：输出健康度评分卡

```
【产品健康度报告】产品：[名称] | 周期：[日期]

总体健康度：[分数]/100 [🟢健康/🟡需关注/🔴告警]

┌─────────────────────────────────────┐
│ 维度       │ 评分 │ 状态 │ 核心风险  │
├─────────────────────────────────────┤
│ 📈 增长    │  XX  │ 🟢   │ [描述]   │
│ 🔄 留存    │  XX  │ 🟡   │ [描述]   │
│ 💡 体验    │  XX  │ 🟢   │ [描述]   │
│ 💰 商业    │  XX  │ 🔴   │ [描述]   │
└─────────────────────────────────────┘

🚨 当前最大风险：[描述]
✅ 当前最强项：[描述]

Top 3 行动项：
1. [优先级最高的改进项]
2. [次优先改进项]
3. [第三改进项]
```

### Step 4：趋势分析（可选）
如用户提供历史数据，输出趋势判断：
- 改善中 ↗ / 稳定 → / 恶化中 ↘
- 预测下一周期风险

## 输出说明
- 评分仅供内部参考，不是精确科学计算
- 重点是识别"最需要关注的维度"和"行动优先级"
- 建议每月更新一次，纳入月报固定模块
