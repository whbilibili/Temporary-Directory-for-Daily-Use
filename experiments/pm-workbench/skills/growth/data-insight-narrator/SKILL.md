# Data Insight Narrator - 数据洞察叙述化工具

## 功能概述

将用户提供的原始数据（数字、表格、指标变化）自动转化为**结构化、可读性强的分析结论段落**。

核心能力：
- 识别整体趋势 vs 结构性分化
- 自动归因（是全局问题还是局部拖累？）
- 分层叙述（整体 → 结构 → 原因 → 建议）
- 三种输出风格，适配不同场景

---

## 使用方式

用户只需粘贴数据，说明风格偏好（可选），Claude 即自动生成叙述段落。

**触发示例：**
- 「帮我把这份数据写成分析结论」
- 「这周数据：搜索QV -0.18% WoW，服务零售UV -14.1%，帮我叙述一下」
- 「把这个表格转成一段可以放进周报的分析」
- 「数据说人话」
- 「帮我写数据结论，管理层汇报用」

---

## 输入格式支持

Claude 能处理以下所有输入形式，**无需用户格式化**：

| 输入类型 | 示例 |
|---|---|
| 纯文字数字 | 「搜索QV W12: 111M，WoW -0.18%，YoY +6.89%」 |
| 逗号/分号分隔 | 「A指标+3%，B指标-5%，C指标+1%」 |
| CSV / Markdown 表格 | 直接粘贴即可 |
| 口语描述 | 「这周搜索基本持平，但酒旅掉了不少」 |
| 多维度混合 | 同时包含 WoW、YoY、绝对值等 |

## 输出风格选项

用户可指定风格，未指定时默认**工作文档版**。

### 🎯 管理层汇报版（精炼）
- 2-4 句话，突出核心结论
- 数字精简，不堆砌
- 语气：客观、有判断力
- 适用：周报摘要、汇报 PPT、高管同步

**示例输出：**
> 本周搜索整体承压但结构性分化明显：QV同比仍正增长（+6.89%），但服务零售与酒旅UV双双下滑14.1%，是主要拖累项。餐饮外卖逆势增长，显示用户高频刚需稳健，建议重点关注中高客单品类转化链路。

---

### 📄 工作文档版（详细）
- 完整四层结构：整体 → 结构 → 归因 → 建议
- 数字完整呈现，逻辑链清晰
- 适用：周报正文、分析文档、复盘报告

**示例输出：**
> **整体表现：** 本周搜索QV达111M，环比微降0.18%，同比增长6.89%，整体保持相对平稳。
>
> **结构分化：** 下降并非全局性——服务零售UV（W07→W12）下滑14.1%，酒旅UV同步下跌14.1%，两类目下滑幅度和节奏高度一致，合计贡献了绝大部分UV降幅。餐饮外卖UV同期增长7.5%，形成明显分化。
>
> **归因判断：** 服务零售与酒旅同步走弱，时间节点与春节后消费回落窗口吻合，叠加中高客单消费信心偏弱的宏观背景，或为季节性 + 消费降级的双重压力。餐饮外卖的逆势增长印证用户搜索需求并未整体萎缩，而是高频刚需在增长、可选消费在流失。
>
> **建议关注：** 重点跟踪酒旅和服务零售的供给侧变化（是否存在商品减少、价格上移），评估是需求问题还是供给侧匹配问题，以决定是否需要运营介入。

---

### 💬 大象推送版（一句话）
- 一句话，含最关键数字 + 核心结论
- 口语化，易于转发
- 适用：群消息、快速同步、进度播报

**示例输出：**
> 本周搜索QV同比+6.89%整体稳，但服务零售和酒旅UV双双-14.1%拖累明显，餐饮外卖+7.5%对冲，结构分化值得关注。
