# AARRR Funnel Analyzer — 增长漏斗诊断工具

**AARRR框架（海盗模型）** 是增长分析的基础框架，五个环节环环相扣。

## 五个环节定义

| 环节 | 关键问题 | 核心指标 |
|---|---|---|
| **A — Acquisition（获客）** | 用户从哪来？获客成本多少？ | CAC、渠道量、渠道质量（LTV/CAC） |
| **A — Activation（激活）** | 用户来了之后有没有体验到核心价值？ | 注册完成率、Aha时刻触达率、D1留存 |
| **R — Retention（留存）** | 用户有没有持续回来？ | D7/D30留存率、回访频率 |
| **R — Revenue（变现）** | 用户有没有产生收入？ | ARPU、转化率、LTV |
| **R — Referral（推荐）** | 用户有没有带来新用户？ | K因子、NPS、推荐率 |

## 工作流程

### Step 1：收集各环节数据

请用户提供（有多少填多少，没有的说明）：
- **获客**：月新增用户数、主要渠道及占比、各渠道CAC
- **激活**：注册完成率、新用户核心行为完成率、D1留存
- **留存**：D7、D30、D90留存率
- **变现**：转化率（免费→付费）、ARPU、LTV
- **推荐**：NPS分数、自然流量占比、K因子（可选）

### Step 2：识别最大瓶颈

**漏斗健康度评估逻辑：**
1. 找到每个环节的行业基准（见下方参考表）
2. 计算每个环节与基准的差距
3. 评估改善空间和可达性
4. **优先修复差距最大、改善最容易的环节**

**各类产品参考基准：**

| 环节 | 消费类App | SaaS工具 | 电商 |
|---|---|---|---|
| 获客→注册转化 | 30-50% | 20-40% | 40-60% |
| 注册→激活 | 40-60% | 30-50% | 50-70% |
| D7留存 | 20-40% | 15-30% | 10-20% |
| D30留存 | 10-20% | 8-15% | 5-10% |
| 免费→付费转化 | 2-5% | 3-8% | — |
| NPS | >30 | >40 | >20 |

### Step 3：深度分析瓶颈环节

**如果获客瓶颈（CAC过高或量不足）：**
- 渠道ROI分布：哪些渠道LTV/CAC>3？
- 有没有高转化低成本的渠道被忽视？
- 产品形态是否适合自然增长（口碑/SEO/内容）？

**如果激活瓶颈（D1留存低）：**
- Aha时刻是什么？新用户触达率多少？
- 注册到首次核心行为的平均时长是多少？
- 有没有用户引导流程？转化率如何？

**如果留存瓶颈（D7/D30跌幅大）：**
- 见 `retention-diagnosis` skill 的详细诊断
- 核心：习惯养成是否发生？使用频率场景是否充足？

**如果变现瓶颈（转化率低或ARPU低）：**
- 用户知道付费能得到什么吗？价值感知够清晰吗？
- 付费门槛（价格/流程）是否过高？
- 有没有合适的"付费时机"设计？

**如果推荐瓶颈（K因子低）：**
- 用户有没有主动推荐的动力？
- 推荐路径是否足够简单？
- 有没有激励机制？激励是否和核心价值相关？
