# stakeholder-alignment-kit

**跨部门对齐工具包** — 帮助产品经理识别利益相关方、诊断对齐障碍、制定跨部门协作策略。

## 触发条件
用户提到：跨部门协作、对齐困难、推不动、stakeholder管理、如何影响没有汇报关系的人、资源争抢。

## 执行步骤

### Step 1：利益相关方地图
对所有相关方评估：
- **影响力**（高/中/低）：对决策的影响程度
- **利益相关度**（高/中/低）：受决策影响程度
- **当前态度**（支持/中立/反对）

### Step 2：四象限策略
```
           高利益相关度
                |
高影响力   [密切管理]    [主动满足需求]
   ---------|------------|----------
低影响力   [定期通知]    [随时监控]
                |
           低利益相关度
```

### Step 3：对齐障碍诊断
| 障碍类型 | 表现 | 解决策略 |
|---|---|---|
| **信息不对称** | 对方不了解你做的事情 | 定期同步，主动透明 |
| **利益冲突** | 对方的目标与你的目标相悖 | 找共同利益，拆分利益 |
| **优先级差异** | 对方有更重要的事情 | 对齐更高层目标，增加紧迫感 |
| **信任缺失** | 以往合作有问题 | 小承诺先建立信任 |
| **流程障碍** | 官僚流程阻碍 | 找流程冠军，升级决策层 |

### Step 4：对齐行动计划
- **对关键反对者**：单独1:1，了解顾虑，找共同利益
- **对关键支持者**：给予认可，请他们帮助影响中立方
- **对决策者**：准备1-page决策文档，聚焦ROI和风险

### Step 5：会议设计原则
- **对齐会 ≠ 信息同步会**（分开开）
- 关键决策前先做预沟通（不在会上第一次暴露分歧）
- 提前准备反对意见的回应

## 输出格式
```
【跨部门对齐方案】项目：[名称]

利益相关方地图：
| 部门/人 | 影响力 | 利益相关度 | 当前态度 | 策略 |
|---|---|---|---|---|

关键阻力来源：
- [谁]：[障碍类型] | 根本原因：[X] | 解法：[Y]

本周行动：
1. [与谁] 1:1 | 目的：[X] | 预期结果：[Y]
2. ...

决策文档要点（1-pager）：
- 背景：[1-2句话]
- 我们要做什么：[具体方案]
- 对你有什么好处：[针对决策者利益]
- 不做的风险：[X]
- 需要你的什么支持：[明确诉求]
```
