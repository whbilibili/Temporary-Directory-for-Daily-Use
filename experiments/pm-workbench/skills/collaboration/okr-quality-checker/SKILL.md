# okr-quality-checker

**OKR质量检验工具** — 帮助产品经理检验OKR是否符合「好OKR」的5大标准，识别常见写法陷阱。

## 触发条件
用户提到：OKR、目标与关键结果、季度目标、写OKR、OKR怎么写、OKR质量。

## 执行步骤

### Step 1：输入OKR内容
用户粘贴OKR，格式如：
O：[目标陈述]
KR1：[关键结果1]
KR2：[关键结果2]

### Step 2：五大标准检验

**O（目标）质量检验**：
- 是否有激励性？（读到时是否让人兴奋）
- 是否描述状态而非动作？（"成为最好"而非"提升"）
- 是否没有数字？（数字放KR，不放O）
- 是否3-5个月内可以评估是否达成？

**KR（关键结果）质量检验**：
- 是否可量化？（有具体数字）
- 是否是结果而非行动？（"用户留存率达到X%"而非"做留存功能"）
- 是否与O直接相关？（KR达成能否保证O达成）
- 是否有挑战性但可达到？（完成率60-70%为佳）

### Step 3：常见陷阱识别
| 陷阱 | 示例 | 改法 |
|---|---|---|
| 任务型KR | KR：上线新版本 | KR：用户使用新版本率>70% |
| KR即O | O就是KR1的内容 | 重新分层 |
| 虚荣指标 | KR：下载量增加 | KR：周活用户增加 |
| 过于保守 | 100%可保证完成 | 提高挑战度 |
| 缺少滞后指标 | 只有领先指标 | 加入结果指标 |

### Step 4：评分与建议
- O得分：X/20
- KR整体得分：X/30
- 总分：X/50
- 改写建议：[具体改法]

## 输出格式
```
【OKR质量报告】

O质量（满分20分）：[X/20]
- 激励性：[✅/⚠️] [说明]
- 状态描述：[✅/⚠️]
- 无数字：[✅/⚠️]
- 时效性：[✅/⚠️]

KR1质量（满分10分）：[X/10]
- 可量化：[✅/⚠️]
- 结果导向：[✅/⚠️]
- 与O关联：[✅/⚠️]

识别到的陷阱：
- [陷阱名称]：[具体问题]

改写建议：
O改为："[改写版本]"
KR1改为："[改写版本]"
```
