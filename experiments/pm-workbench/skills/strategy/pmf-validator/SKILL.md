# PMF Validator — 产品市场匹配验证工具

**核心工具：为[目标用户]提供[核心价值]的[产品/服务]**

来源：王莆中（美团产品委员会顾问）在产品大咖秀第61、74期的分享。

## PMF公式解析

```
为 [谁] 提供 [什么价值] 的 [什么产品/服务]

例：
美团买药 → "为中青年提供自费应急的购药服务"
Twitter  → "为任何人提供极低门槛的公开即时表达渠道"
理想汽车 → "为有两个孩子的中产家庭提供宽敞豪华的新能源家庭用车"
```

**好的PMF一句话要做到：**
- 目标用户：具体到可以找到这群人
- 核心价值：说清楚解决了什么问题/提供了什么体验
- 产品形态：说清楚用什么方式交付价值

## 工作流程

### Step 1：获取当前PMF描述

请用户：
1. 用一句话描述：你的产品是为谁、提供什么服务？
2. 这个产品/业务现在的核心用户群体是谁？
3. 他们用什么方式解决这个需求（旧体验）？

### Step 2：PMF质量诊断（7项检查）

**① 用户清晰度**
- [ ] 目标用户是否具体到可以识别？（"年轻人"太模糊，"25-35岁在大城市独居的职场人"是具体的）
- 评分：1=极模糊，5=非常具体

**② 价值清晰度**
- [ ] 提供的价值是否是用户真正在意的，还是产品经理认为用户在意的？
- [ ] 价值是功能性的还是情感性的？哪个更重要？
- 评分：1=价值不清晰，5=价值非常明确

**③ 独特性**
- [ ] 这个PMF有没有竞争对手也在做完全一样的事？
- [ ] 如果有，我们的差异在哪（更便宜/更快/更适配/某个细分场景）？
- 评分：1=完全同质化，5=独特壁垒

**④ 市场颗粒度**
- [ ] 定义的市场粒度是否合适？（不要"14亿人"，也不要"北京某小区居民"）
- [ ] TAM（可寻址市场）用这个定义算出来是合理的范围吗？
- 评分：1=严重偏大或偏小，5=颗粒度恰当

**⑤ 动态性**
- [ ] 满足这个需求的方式是否可能在3年内被替代（AI/新技术/新模式）？
- [ ] 有没有考虑AI对这个PMF的冲击或机会？
- 评分：1=忽略了变化，5=已充分考虑

**⑥ 可验证性**
- [ ] 如何验证这个PMF是否成立？有没有可测量的指标？
- [ ] 多少用户满意、留存、推荐，算PMF验证通过？
- 评分：1=无法验证，5=有清晰验证标准

**⑦ 扩展性**
- [ ] 这个PMF打通之后，如何扩大市场？（改变[谁]？改变[价值]？改变[方式]？）
- 评分：1=是个死胡同，5=有清晰的扩展路径

### Step 3：输出诊断报告

```
## 🎯 PMF 验证报告

**当前PMF：** "[用户的一句话]"

### 优化建议版本

> "为[更精确的用户]提供[更清晰的价值]的[更具体的产品/服务]"

### 7维评分

| 维度 | 得分 | 关键问题 |
|---|---|---|
| 用户清晰度 | X/5 | [具体问题] |
| 价值清晰度 | X/5 | ... |
| 独特性 | X/5 | ... |
| 市场颗粒度 | X/5 | ... |
| 动态性 | X/5 | ... |
| 可验证性 | X/5 | ... |
| 扩展性 | X/5 | ... |
| **总分** | **XX/35** | |

### 📌 核心结论

[PMF是否清晰，最大的问题是什么]

### 🚀 扩大市场的3个方向

基于 "为[谁]提供[什么]的[产品]" 的三个变量，可以：
1. **扩大[谁]**：[具体方向]
2. **丰富[价值]**：[具体方向]
3. **改变[方式]**：[具体方向]
```

### Step 4：AI时代PMF重评估（可选）

对现有产品，额外检查AI的冲击：
- **PMF消失风险**：AI会直接替代我们的产品/服务吗？
- **PMF升级机会**：AI能让我们的核心价值主张做得更好吗？
- **PMF新生方向**：AI是否为目标用户创造了新的需求？

详细PMF案例和三种形成路径，见：`references/pmf-cases.md`
