# 决策日志

> 记录每一个重要的产品决策。目的：防止重复讨论已决事项、为后来者提供决策背景。

## 格式规范

每条决策包含：

```markdown
### DEC-{序号}: {决策标题}

- **日期**: YYYY-MM-DD
- **决策者**: [谁做的决定]
- **背景**: [为什么需要做这个决定]
- **考虑的方案**:
  - 方案A: [描述] → [优劣]
  - 方案B: [描述] → [优劣]
- **最终决策**: [选了什么]
- **理由**: [为什么选它]
- **影响范围**: [这个决定影响了哪些功能/模块]
- **回顾条件**: [什么情况下需要重新审视这个决策]
```

## 使用说明

- **什么该记录**：影响产品方向、功能取舍、优先级调整的决策
- **什么不用记录**：纯执行层面的小调整（按钮颜色、文案措辞等）
- **谁来维护**：每次 PRD 产出时，AI 自动检查是否有需要记录的决策
- **何时引用**：当新需求与历史决策冲突时，必须先引用相关决策，再讨论是否推翻
