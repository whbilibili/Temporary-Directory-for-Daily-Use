# 用户画像

> 所有功能设计必须能指向至少一个具体画像。如果无法指向，说明这个功能可能不该做。

---

## 画像模板

每个画像包含以下维度：

```yaml
id: persona-001
name: "画像昵称"
role: "职业/角色"
age_range: "25-35"
tech_savvy: "高/中/低"
core_need: "一句话核心需求"
pain_points:
  - 痛点1
  - 痛点2
goals:
  - 目标1
  - 目标2
usage_scenario: "典型使用场景描述"
quote: "一句代表性的话（让画像鲜活）"
```

## 使用说明

- PRD 中引用画像时使用 ID（如 `persona-001`），不要重复描述画像内容
- 新增画像需要有数据/调研支撑，不能凭空捏造
- 画像是活的文档，随着用户调研的深入持续更新
- 建议每个产品维护 3-5 个核心画像，不宜过多
