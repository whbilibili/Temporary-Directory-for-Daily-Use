# 产品规格目录

本目录存放实验目标、验收标准和产品需求文档。

## 文件命名规范

- 实验规格: `SPEC-主题.md`（例：`SPEC-验收标准.md`）
- 用户故事: `US-序号-主题.md`（例：`US-001-需求阶段技能验证.md`）

## 实验总目标

验证以下假设：

1. **假设 H1**: 多个 AI Agent 技能可以通过 harness 文件无缝串联，覆盖产研全链路
2. **假设 H2**: 技能间的上下文传递断点可以被识别并修复
3. **假设 H3**: 技能编排模板可以被提炼并复用到其他项目

## 验收标准

| 标准 | 验证方式 | 通过条件 |
|------|---------|---------|
| 全链路覆盖 | 逐阶段执行技能 | 5 个阶段均有技能成功执行 |
| 状态传递 | 检查 harness 文件 | 技能间状态通过文件正确传递 |
| 断点识别 | 记录失败案例 | 至少识别 1 个断点并提出修复方案 |
| 模板产出 | 检查 references/ | 有可复用的技能编排模板文档 |
