## 约定

- 需求文档回答“为什么做、做到哪”
- 功能规格回答“系统必须如何工作”
- 迭代设计文档（`*-iteration-spec.md`）针对单个页面/能力深化，基于 MVP 文档扩展
- UI 设计规格（`*-ui-spec.md`）承接同名迭代 PRD 的产品决策，回答“界面长什么样、怎么交互”
