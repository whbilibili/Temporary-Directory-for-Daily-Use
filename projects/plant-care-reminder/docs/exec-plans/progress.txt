### [Blockers & Solutions]
- 现有 CSS 中存在硬编码的蓝色(#2563EB)/橙色(#F97316) Token → VIS-001 已全量替换为 botanical palette（已解决）。
- 【VIS-001 期间发现并处理】仓库存在 pre-existing 红测：单元测试（PlantForm/PlantImageField）断言英文 label，而 AppRouter.smoke 测试断言中文 label，二者对同一组件矛盾，源码无论中英文必有一组红。经用户确认采用「源码统一中文 + 同步改单元测试断言为中文」方案修绿。副作用：PlantForm.tsx/PlantImageField.tsx/plantSchema.ts/uploadPlantImage.ts 的文案已中文化，**这部分实际提前完成了 VIS-002（中文文案统一）的一部分工作**，VIS-002 执行时应核对剩余范围避免重复。
- iPhone PWA clipboard API 不稳定 → VIS-010 实现完整的 fallback 面板，不依赖 clipboard。
- 页面间视觉碎片化风险 → VIS-001 的全局 Token + VIS-013 的收尾走查形成闭环。
