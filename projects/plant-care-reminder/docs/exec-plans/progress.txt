### [Current Focus]
`PLANT-004` 已完成：植物编辑流已经接通。后端 [plants.ts](../app/convex/plants.ts) 新增了 `getPlantForEdit` query 和 `updatePlant` mutation，前端 [EditPlantPage.tsx](../app/src/features/plants/EditPlantPage.tsx) 通过 `/plants/:plantId/edit` 复用同一套 `PlantForm`，能预填充现有字段、保留原图或替换图片，更新成功后回到 `/plants`。下一线任务切换为 `PLANT-005`。

### [Key Decisions]
- 这轮没有为 edit 单独造第二套 form state，而是继续复用 `PlantForm` / `usePlantForm`，只在编辑页额外注入 query 回来的初始值。
- Router 这轮补了最小动态路径解析能力：真实 URL 允许 `/plants/:plantId/edit`，内部壳路径统一收敛成 `/plants/edit` 并携带 `plantId` 参数，避免提前把整套路由系统重写成通用 matcher。
- `updatePlant` 继续沿用 API contract 的 `note` 单数名，但 patch 到现有 schema 时仍映射为 `notes`，同时允许 `imageStorageId` 保持原值不变，满足“替换或保留当前图片”两种路径。

### [Blockers & Solutions]
- 当前 router 之前只支持静态路径，`/plants/:plantId/edit` 无法识别；这轮通过最小动态解析补上 `plantId` 参数，不扩散到其他业务路由。
- `usePlantForm` 之前只在 mount 时吃一次初始值，不足以承接编辑页的异步预填充；这轮补了对 `initialValue` 变化的同步逻辑，避免 edit 页手写重复 reset 流程。
- 浏览器级移动端验证依旧受宿主 Playwright 限制影响，所以这轮以 `npm run test` 和 `npx convex dev --once --typecheck enable` 为主，没有伪造浏览器截图结果。
