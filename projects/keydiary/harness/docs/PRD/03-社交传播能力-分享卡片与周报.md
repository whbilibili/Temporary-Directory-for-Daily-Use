# Phase 3：社交传播能力 — 分享卡片与周报

> **目标**：让用户能一键将日记/周报导出为精美的图片卡片，适合分享到社交媒体，形成自传播。  
> **验收标准**：点击"生成分享卡片" → 弹出预览 → 点击"保存图片" → 得到一张竖版精美 PNG → 可直接发到朋友圈/Twitter。  
> **预计工时**：5-7 天（全职）  
> **前置依赖**：Phase 2（完整日记页面 + 历史数据）  
> **后续被依赖**：Phase 4 的年度报告复用本期的卡片渲染引擎

### 2.3 渲染方案

使用 OffscreenCanvas 在前端生成图片：

```typescript
// lib/card-renderer.ts

export async function renderDailyCard(data: DailyCardData): Promise<Blob> {
  const canvas = new OffscreenCanvas(1080, 1920);
  const ctx = canvas.getContext('2d')!;
  
  // 1. 绘制背景渐变
  const gradient = ctx.createLinearGradient(0, 0, 0, 1920);
  gradient.addColorStop(0, '#1a1a2e');
  gradient.addColorStop(1, '#16213e');
  ctx.fillStyle = gradient;
  ctx.fillRect(0, 0, 1080, 1920);
  
  // 2. 绘制日期标题
  ctx.fillStyle = '#e0e0e0';
  ctx.font = 'bold 36px "SF Pro Display", system-ui';
  ctx.fillText(data.dateFormatted, 80, 120);
  
  // 3. 绘制迷你热力图
  renderMiniHeatmap(ctx, data.heatmap, 80, 180, 920, 320);
  
  // 4. 绘制数据区块
  renderStats(ctx, data.highlights, 80, 550);
  
  // 5. 绘制迷你 KPM 曲线
  renderMiniKpmCurve(ctx, data.kpmTimeline, 80, 1050, 920, 200);
  
  // 6. 绘制 Top 按键
  renderTopKeys(ctx, data.topKeys, 80, 1350);
  
  // 7. 品牌水印
  ctx.fillStyle = 'rgba(255, 255, 255, 0.4)';
  ctx.font = '24px "SF Pro Display", system-ui';
  ctx.textAlign = 'center';
  ctx.fillText('Made with 击刻 KeyDiary · keydiary.app', 540, 1860);
  
  return canvas.convertToBlob({ type: 'image/png', quality: 0.92 });
}
```

### 2.4 保存逻辑

```rust
// Tauri Command：保存图片到用户选择的位置
#[tauri::command]
async fn save_card_image(app: AppHandle, png_data: Vec<u8>) -> Result<String, String> {
    use tauri_plugin_dialog::DialogExt;
    
    let path = app.dialog()
        .file()
        .add_filter("PNG Image", &["png"])
        .set_file_name(&format!("击刻-{}.png", Local::now().format("%Y%m%d")))
        .blocking_save_file();
    
    if let Some(path) = path {
        std::fs::write(&path, &png_data).map_err(|e| e.to_string())?;
        Ok(path.to_string_lossy().to_string())
    } else {
        Err("用户取消".to_string())
    }
}
```

## 3. 每周周报

### 3.1 周报数据结构

```rust
#[derive(Serialize)]
pub struct WeeklyReport {
    pub week_start: String,         // "2026-05-19"
    pub week_end: String,           // "2026-05-25"
    pub total_keystrokes: u64,      // 本周总击键
    pub daily_average: u64,         // 日均击键
    pub total_active_hours: f32,    // 总活跃时间（小时）
    pub most_productive_day: String, // 最高效的一天
    pub most_productive_kpm: u32,   // 那天的峰值 KPM
    pub total_flow_minutes: u32,    // 本周心流总时长
    pub top_apps: Vec<AppStat>,     // 本周应用 Top 5
    pub daily_breakdown: Vec<DayStat>, // 7 天逐日数据
    pub fun_fact: String,           // 趣味文案
}
```

### 3.2 趣味文案生成（纯规则，不用 AI）

```rust
fn generate_fun_fact(report: &WeeklyReport) -> String {
    let pages = report.total_keystrokes / 2500;
    let novels = report.total_keystrokes / 80000;
    
    if novels > 0 {
        format!("本周你按键 {} 次，相当于写了 {} 部短篇小说！", 
                report.total_keystrokes.to_formatted(), novels)
    } else if pages > 50 {
        format!("本周你按键 {} 次，相当于打了一本 {} 页的小册子。", 
                report.total_keystrokes.to_formatted(), pages)
    } else {
        format!("本周你按键 {} 次，活跃了 {:.1} 小时。", 
                report.total_keystrokes.to_formatted(), report.total_active_hours)
    }
}
```

### 3.4 周报触发时机

- **自动生成**：每周一 00:01，为上一周生成周报数据并存入 `weekly_reports` 表
- **手动触发**：用户可在"历史"页面中查看任意一周的周报
- **通知提醒**：周一首次打开 app 时，弹出"你的上周周报已生成"通知

### 3.5 新增数据库表

```sql
CREATE TABLE IF NOT EXISTS weekly_reports (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    week_start      TEXT NOT NULL UNIQUE,  -- "2026-05-19"
    week_end        TEXT NOT NULL,         -- "2026-05-25"
    report_json     TEXT NOT NULL,         -- 完整报告的 JSON
    created_at      TEXT NOT NULL DEFAULT (datetime('now', 'localtime'))
);
```

## 4. 交互流程

### 4.1 日记页面新增"分享"按钮

```
[📤 生成分享卡片]  ← 主窗口右上角
```

点击后流程：

1. 收集当前日期的所有数据
2. 调用 `renderDailyCard()` 生成 PNG
3. 弹出预览模态窗口（显示卡片缩略图）
4. 用户选择：[保存图片] [复制到剪贴板] [取消]
5. 保存/复制完成后 toast 提示

### 4.2 周报入口

在主窗口新增 Tab 导航：

```
[ 📖 日记 ]  [ 📊 周报 ]
```

周报 Tab 内容：
- 顶部：周选择器（← 第20周 →）
- 中间：周报卡片预览（在 app 内直接渲染）
- 底部：[📤 导出图片]

## 7. 设计注意事项

**字体选择**：卡片中使用系统字体（SF Pro / PingFang SC），避免字体许可问题。

**配色方案（暗色卡片）**：
- 背景：`#1a1a2e` → `#16213e` 渐变
- 主文字：`#e0e0e0`
- 强调数字：`#4fd1c5`（青绿色，科技感）
- 次要文字：`rgba(255, 255, 255, 0.6)`
- 分割线：`rgba(255, 255, 255, 0.1)`

**避免的坑**：
- Canvas 在 Tauri webview 中的 DPI 处理（需要 `devicePixelRatio` 缩放）
- 中文字体渲染：确保 `font-family` fallback 到 PingFang SC
- PNG 导出大小控制：1080×1920 @ 92% quality 通常 < 500KB
