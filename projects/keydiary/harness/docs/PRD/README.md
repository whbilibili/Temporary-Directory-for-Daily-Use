## 核心设计原则

1. **隐私第一**：不记录按键序列，不上传数据，所有数据本地存储
2. **极致轻量**：包体积 < 10MB，CPU < 0.5%，内存 < 30MB
3. **即装即用**：无需注册，无需联网，授权权限后立即可用
4. **数据讲故事**：不做冷冰冰的统计报表，做有温度的视觉日记
5. **社交传播基因**：每一页日记/周报都天然适合分享
