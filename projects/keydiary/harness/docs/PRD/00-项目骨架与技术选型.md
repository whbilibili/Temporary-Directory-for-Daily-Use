# Phase 0：项目骨架与技术选型

> **目标**：搭建 Tauri 2.0 项目骨架，跑通从 Rust 后端到 Web 前端的通信链路，在系统托盘看到应用图标。  
> **验收标准**：双击启动 app → 菜单栏/托盘出现图标 → 点击图标弹出窗口显示 "Hello, KeyDiary"。  
> **预计工时**：0.5-1 天  
> **前置依赖**：无（这是第一步）  
> **后续被依赖**：Phase 1 的所有功能都建立在此骨架之上

---

## 1. 技术选型确认

### 1.1 桌面框架：Tauri 2.0

**选择理由**：

- Rust 后端：内存安全、性能极高、适合系统级按键监听
- Web 前端：用 Svelte/React 做 UI，开发效率高
- 包体积 < 10MB（Electron 动辄 100MB+）
- 内置系统托盘、窗口管理、自动更新能力
- 活跃社区，2.0 版本稳定

**版本要求**：`@tauri-apps/cli >= 2.0`

### 1.2 前端框架：Svelte 5 + Vite

**选择理由**：

- 编译时响应式，运行时零框架开销
- 代码量少，适合单人项目快速推进
- 与 Tauri 的 Vite 模板完美兼容

### 1.3 数据存储：SQLite (via rusqlite)

**选择理由**：

- 单文件数据库，用户数据可见、可备份
- 嵌入式，无需安装任何外部服务
- 性能足够（日写入量级：~10 万条/天 = 完全无压力）

### 1.4 按键监听（Phase 1 实现，此处只做技术确认）

| 平台 | 方案 | Rust crate |
|------|------|-----------|
| macOS | CGEventTap (Core Graphics) | `core-graphics` + `core-foundation` |
| Windows | Raw Input API | `winapi` 或 `windows-rs` |

### 1.5 可视化：D3.js + Canvas

- D3.js：热力图、折线图、饼图的标准选择
- Canvas 2D：性能敏感的实时渲染场景
- MVP 阶段不引入 WebGL，保持简单

## 3. Phase 0 具体任务

### 3.1 初始化 Tauri + Svelte 项目

```bash
# 创建项目
npm create tauri-app@latest keydiary -- --template svelte-ts

# 进入项目
cd keydiary

# 安装依赖
npm install

# 验证能否运行
npm run tauri dev
```

### 3.2 配置系统托盘

在 `tauri.conf.json` 中启用系统托盘：

```json
{
  "app": {
    "trayIcon": {
      "id": "main-tray",
      "iconPath": "icons/tray-icon.png",
      "iconAsTemplate": true,
      "menuOnLeftClick": false
    }
  }
}
```

托盘菜单项：

- "打开击刻" → 显示主窗口
- "暂停采集" / "恢复采集"（Phase 1 实现逻辑，此处只留 UI 占位）
- "退出"

### 3.3 配置窗口行为

- 默认隐藏主窗口（app 启动只显示托盘图标）
- 点击托盘图标 → 显示/隐藏主窗口
- 主窗口尺寸：800×600，可调整大小，最小 640×480
- 关闭窗口 = 隐藏到托盘（不退出进程）

### 3.4 Rust 侧基础结构

```rust
// main.rs 伪代码结构
fn main() {
    tauri::Builder::default()
        .plugin(tauri_plugin_shell::init())
        .setup(|app| {
            // 初始化数据库
            db::init(app)?;
            // 初始化托盘
            tray::init(app)?;
            Ok(())
        })
        .invoke_handler(tauri::generate_handler![
            commands::get_app_status,
        ])
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

### 3.5 前端 Hello World

```svelte
<!-- App.svelte -->
<script lang="ts">
  import { invoke } from '@tauri-apps/api/core';

  let status = $state('loading...');

  async function checkStatus() {
    status = await invoke('get_app_status');
  }

  $effect(() => { checkStatus(); });
</script>

<main>
  <h1>击刻 KeyDiary</h1>
  <p>状态：{status}</p>
</main>
```

Phase 0 只创建空数据库文件，表结构在 Phase 1 创建。
