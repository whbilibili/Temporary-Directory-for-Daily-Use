## 2. 数据库 Schema

### 表：`key_events`

存储按键频率数据，按 5 分钟桶聚合：

```sql
CREATE TABLE IF NOT EXISTS key_events (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    date        TEXT NOT NULL,           -- '2026-05-25'
    time_bucket TEXT NOT NULL,           -- '14:05' (5分钟粒度，取整到 0/5)
    key_code    INTEGER NOT NULL,        -- 物理键码 (macOS virtual keycode)
    key_label   TEXT NOT NULL,           -- 可读标签 ('A', 'Space', 'Cmd+C')
    count       INTEGER NOT NULL DEFAULT 0,  -- 该桶内按下次数
    created_at  TEXT NOT NULL DEFAULT (datetime('now', 'localtime')),
    
    UNIQUE(date, time_bucket, key_code)  -- 同一桶同一键只有一条记录（UPSERT）
);

CREATE INDEX idx_key_events_date ON key_events(date);
CREATE INDEX idx_key_events_date_key ON key_events(date, key_code);
```

### 表：`daily_summary`

每日汇总，供快速查询（避免每次全表扫描）：

```sql
CREATE TABLE IF NOT EXISTS daily_summary (
    date            TEXT PRIMARY KEY,     -- '2026-05-25'
    total_keystrokes INTEGER NOT NULL DEFAULT 0,
    active_minutes  INTEGER NOT NULL DEFAULT 0,  -- 有击键的5分钟桶数量 × 5
    peak_kpm        INTEGER NOT NULL DEFAULT 0,  -- 最高每分钟击键数
    updated_at      TEXT NOT NULL DEFAULT (datetime('now', 'localtime'))
);
```

## 3. Rust 后端：按键采集模块

### 3.1 架构概览

```
┌─────────────────────────────────────────────┐
│  CGEventTap (macOS 系统级事件监听)            │
│  监听 keyDown 事件                           │
└──────────────────┬──────────────────────────┘
                   │ 事件回调（key_code, timestamp）
                   ▼
┌─────────────────────────────────────────────┐
│  Aggregator (内存聚合器)                      │
│  HashMap<(date, bucket, key_code), count>    │
│  每 60 秒 flush 到 SQLite                    │
└──────────────────┬──────────────────────────┘
                   │ batch INSERT/UPSERT
                   ▼
┌─────────────────────────────────────────────┐
│  SQLite (data.db)                            │
└─────────────────────────────────────────────┘
```

### 3.2 CGEventTap 监听实现要点

```rust
// collector.rs 关键逻辑（伪代码）

use core_graphics::event::{CGEvent, CGEventTap, CGEventType};

pub fn start_listener(aggregator: Arc<Mutex<Aggregator>>) {
    // 创建事件监听
    let tap = CGEventTap::new(
        CGEventTapLocation::Session,
        CGEventTapPlacement::HeadInsert,
        CGEventTapOptions::ListenOnly,  // ⚠️ 只监听，不拦截/修改事件
        vec![CGEventType::KeyDown],
        move |_, event_type, event| {
            if event_type == CGEventType::KeyDown {
                let key_code = event.get_integer_value_field(CGEventField::KeyboardEventKeycode);
                aggregator.lock().unwrap().record(key_code as u16);
            }
            None  // 不修改事件
        }
    );
    
    // 将 tap 加入 RunLoop
    let run_loop_source = tap.mach_port_create_run_loop_source(0);
    CFRunLoop::get_current().add_source(&run_loop_source, kCFRunLoopCommonModes);
    CFRunLoop::run_current();
}
```

### 3.3 内存聚合器

```rust
// aggregator.rs

pub struct Aggregator {
    buffer: HashMap<(String, String, u16), u32>,  // (date, bucket, keycode) -> count
    last_flush: Instant,
}

impl Aggregator {
    pub fn record(&mut self, key_code: u16) {
        let now = Local::now();
        let date = now.format("%Y-%m-%d").to_string();
        let minute = now.minute() - (now.minute() % 5);  // 对齐到5分钟
        let bucket = format!("{:02}:{:02}", now.hour(), minute);
        
        let key = (date, bucket, key_code);
        *self.buffer.entry(key).or_insert(0) += 1;
        
        // 每60秒自动flush
        if self.last_flush.elapsed() > Duration::from_secs(60) {
            self.flush();
        }
    }
    
    pub fn flush(&mut self) {
        // batch UPSERT 到 SQLite
        // INSERT OR REPLACE INTO key_events (date, time_bucket, key_code, key_label, count)
        // VALUES (?, ?, ?, ?, ?)
        // ON CONFLICT(date, time_bucket, key_code) 
        // DO UPDATE SET count = count + excluded.count;
        
        self.buffer.clear();
        self.last_flush = Instant::now();
    }
}
```

### 3.4 macOS 权限处理

按键监听需要 **Accessibility 权限**（系统偏好设置 → 安全性与隐私 → 辅助功能）。

**权限引导流程**：

1. App 启动时检测是否已获得权限：`AXIsProcessTrusted()`
2. 若未授权 → 前端显示引导页面（截图 + 文字说明如何授权）
3. 提供 "打开系统设置" 按钮：`open x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility`
4. 后台轮询检测权限状态（每 2 秒），授权后自动开始采集

### 4.2 热力图渲染逻辑

```svelte
<!-- components/KeyboardHeatmap.svelte -->
<script lang="ts">
  import { invoke } from '@tauri-apps/api/core';
  import { QWERTY_LAYOUT } from '$lib/keyboard-layout';
  
  let heatmapData: Map<number, number> = $state(new Map());
  let maxCount = $state(1);
  
  async function refresh() {
    const data = await invoke('get_today_heatmap');
    heatmapData = new Map(data.map(d => [d.key_code, d.total]));
    maxCount = Math.max(...heatmapData.values(), 1);
  }
  
  // 每 10 秒刷新一次
  $effect(() => {
    refresh();
    const interval = setInterval(refresh, 10_000);
    return () => clearInterval(interval);
  });
  
  function getColor(keyCode: number): string {
    const count = heatmapData.get(keyCode) || 0;
    const intensity = count / maxCount;  // 0-1
    // 冷色(蓝) → 暖色(红) 渐变
    // HSL: H 从 240(蓝) → 0(红)，S=80%, L=50%
    const hue = 240 - intensity * 240;
    return `hsl(${hue}, 80%, ${50 + (1 - intensity) * 30}%)`;
  }
</script>

<div class="keyboard-container">
  <svg viewBox="0 0 1000 400" class="keyboard-svg">
    {#each QWERTY_LAYOUT as key}
      <g class="key-group">
        <rect
          x={key.x * 980 + 10}
          y={key.y * 380 + 10}
          width={key.width * 980 - 4}
          height={key.height * 380 - 4}
          rx="6"
          fill={getColor(key.code)}
          stroke="#333"
          stroke-width="1"
        />
        <text
          x={key.x * 980 + key.width * 490}
          y={key.y * 380 + key.height * 200 + 5}
          text-anchor="middle"
          fill="white"
          font-size="12"
        >
          {key.label}
        </text>
      </g>
    {/each}
  </svg>
</div>
```

## 5. 隐私安全设计

### 5.1 不记录什么（硬性约束）

- ❌ 不记录按键的顺序（无法还原输入内容）
- ❌ 不记录按键的时间戳精确序列（只聚合到 5 分钟桶）
- ❌ 不在 SecureInput 模式下采集（密码输入框）
- ❌ 不做任何网络通信

### 5.2 SecureInput 检测

```rust
use core_graphics::event::CGSIsSecureEventInputSet;

fn is_secure_input_active() -> bool {
    unsafe { CGSIsSecureEventInputSet() }
}

// 在事件回调中：
if is_secure_input_active() {
    return None;  // 跳过，不记录
}
```

### 5.3 数据存储透明

- 数据库路径写入主窗口底部："数据存储于 ~/.keydiary/data.db"
- 提供"打开数据目录"按钮，让用户随时查看/删除

## 8. 已知技术难点

| 难点 | 解法 |
|------|------|
| CGEventTap 需要在独立线程的 RunLoop 中运行 | 使用 `std::thread::spawn` + `CFRunLoop::run_current()` |
| Aggregator 的线程安全 | `Arc<Mutex<Aggregator>>`，flush 时短暂锁定 |
| 首次安装时用户不知道如何授权 | 引导页 + 动图/截图说明 + 一键跳转系统设置 |
| macOS 13+ 对 CGEventTap 的限制 | 确保 Info.plist 声明了正确的 usage description |
