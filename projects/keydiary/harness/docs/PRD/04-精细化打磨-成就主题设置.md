# Phase 4：精细化打磨 — 成就系统、多主题与高级设置

> **目标**：为产品增加"可玩性"（成就系统）和"个性化"（多主题），并完善用户控制能力（高级设置）。使产品从"能用"进化到"好用且有粘性"。  
> **验收标准**：累积使用 3 天后 → 自动解锁至少 1 个成就 → 成就有动画庆祝；主题可切换 → 热力图配色跟随变化。  
> **预计工时**：5-7 天（全职）  
> **前置依赖**：Phase 2（日记体验 + 历史数据）、Phase 3（卡片渲染引擎）

## 2. 成就系统

### 2.1 设计原则

- **无压力**：成就是"发现彩蛋"，不是"每日任务"。不设定期限，不施加压力。
- **数据驱动**：所有成就的判定纯基于已采集数据的聚合查询，不需要额外采集。
- **低频惊喜**：不是每天都能解锁，但解锁时有仪式感（动画 + 通知）。

### 2.2 成就列表（V1：8 个）

| ID | 名称 | 图标 | 解锁条件 | 分类 |
|----|------|------|----------|------|
| `first_day` | 初次记录 | 🌱 | 首次使用击刻完成一天的数据采集 | 里程碑 |
| `10k_club` | 万键俱乐部 | ⌨️ | 单日击键突破 10,000 次 | 里程碑 |
| `100k_club` | 十万大关 | 🏔 | 单日击键突破 100,000 次 | 里程碑 |
| `flow_master` | 心流大师 | 🧘 | 连续 7 天每天心流 > 30 分钟 | 习惯 |
| `vim_disciple` | Vim 信徒 | 🥷 | 累计 hjkl 使用次数超过方向键 | 技能 |
| `shortcut_ninja` | 快捷键忍者 | ⚡ | 单日快捷键组合使用 > 300 次 | 技能 |
| `night_owl` | 夜猫子 | 🦉 | 凌晨 0:00-4:00 期间击键 > 1000 次（连续 3 天） | 生活 |
| `steady_hand` | 稳定输出 | 📈 | 连续 14 天日击键数波动 < 25% | 习惯 |

### 2.4 成就判定引擎

每次 Aggregator flush 时（每 60 秒），异步检查成就条件：

```rust
// achievement_checker.rs

pub fn check_achievements(db: &Connection) -> Vec<NewlyUnlocked> {
    let mut newly_unlocked = vec![];
    
    // first_day：检查今天是否有数据
    if !is_unlocked(db, "first_day") {
        let today_count = query_today_total(db);
        if today_count > 0 {
            unlock(db, "first_day");
            newly_unlocked.push("first_day");
        }
    }
    
    // 10k_club：今日击键 > 10000
    if !is_unlocked(db, "10k_club") {
        let today_count = query_today_total(db);
        update_progress(db, "10k_club", (today_count as f64 / 10000.0).min(1.0));
        if today_count >= 10000 {
            unlock(db, "10k_club");
            newly_unlocked.push("10k_club");
        }
    }
    
    // flow_master：连续7天心流>30分钟
    if !is_unlocked(db, "flow_master") {
        let consecutive = query_consecutive_flow_days(db, 30); // 30分钟阈值
        update_progress(db, "flow_master", (consecutive as f64 / 7.0).min(1.0));
        if consecutive >= 7 {
            unlock(db, "flow_master");
            newly_unlocked.push("flow_master");
        }
    }
    
    // ... 其他成就类似
    
    newly_unlocked
}
```

### 2.5 解锁动画

解锁时：
1. Rust 侧通过 `app.emit("achievement_unlocked", payload)` 通知前端
2. 前端弹出全屏 overlay 动画（2-3 秒）：
   - 成就图标从中心放大弹入
   - 金色粒子环绕
   - 成就名称 + "已解锁！" 文字渐入
   - 自动消失或点击关闭

```svelte
<!-- components/AchievementUnlock.svelte -->
<script lang="ts">
  import { listen } from '@tauri-apps/api/event';
  import { fly, scale } from 'svelte/transition';
  
  let show = $state(false);
  let achievement = $state(null);
  
  listen('achievement_unlocked', (event) => {
    achievement = event.payload;
    show = true;
    setTimeout(() => show = false, 3000);
  });
</script>

{#if show}
  <div class="achievement-overlay" transition:fade>
    <div class="achievement-card" in:scale={{ duration: 500, start: 0.3 }}>
      <span class="icon">{achievement.icon}</span>
      <h2>{achievement.name}</h2>
      <p>成就已解锁！</p>
    </div>
  </div>
{/if}
```

```svelte
  import { currentTheme } from '$lib/stores/settings';
  import { THEMES } from '$lib/themes';

        root.style.setProperty(`--color-${camelToKebab(key)}`, value);
```

### 3.3 热力图色谱适配

热力图的 `getColor()` 函数需要根据当前主题的 `heatmapCold/Warm/Hot` 做三段插值：

```typescript
function getHeatmapColor(intensity: number, theme: Theme): string {
  // intensity: 0 (最少) → 1 (最多)
  if (intensity < 0.5) {
    return interpolateColor(theme.colors.heatmapCold, theme.colors.heatmapWarm, intensity * 2);
  } else {
    return interpolateColor(theme.colors.heatmapWarm, theme.colors.heatmapHot, (intensity - 0.5) * 2);
  }
}
```

## 4. 高级设置面板

### 4.1 设置项

| 设置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 视觉主题 | 选择器 | cyberpunk | 4 选 1 |
| 键盘布局 | 选择器 | QWERTY | QWERTY / Colemak / Dvorak |
| 排除应用 | 列表编辑 | [] | 在这些应用中暂停采集 |

| 开机自启 | 开关 | 关闭 | 是否随系统启动 |

| 导出数据 | 按钮 | - | 导出为 JSON 或 CSV |
| 清除数据 | 按钮（危险） | - | 二次确认后删除全部历史 |

### 4.5 键盘布局切换

预置 3 套布局坐标文件：

- `layouts/qwerty.json`
- `layouts/colemak.json`
- `layouts/dvorak.json`

切换布局后：
- 热力图重新渲染（按键位置变化）
- keycode → label 映射不变（物理键码不变，只是键帽标签变了）
- 需要重新映射 label 显示

## 5. 开机自启

### macOS

```rust
use auto_launch::AutoLaunchBuilder;

fn set_auto_launch(enabled: bool) {
    let auto_launch = AutoLaunchBuilder::new()
        .set_app_name("KeyDiary")
        .set_app_path(std::env::current_exe().unwrap().to_str().unwrap())
        .build()
        .unwrap();
    
    if enabled {
        auto_launch.enable().unwrap();
    } else {
        auto_launch.disable().unwrap();
    }
}
```
