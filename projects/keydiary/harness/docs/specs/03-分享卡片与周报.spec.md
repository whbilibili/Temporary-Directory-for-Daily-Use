# Spec: Phase 3 — 社交传播能力：分享卡片与周报

## Objective

让用户能一键将日记/周报导出为精美的图片卡片，适合分享到社交媒体，形成自传播闭环。

**目标用户**：已使用数天、想在社交媒体分享打字数据的用户。

**核心价值**：赋予产品自传播能力——用户分享卡片 -> 朋友看到 -> 下载使用 -> 增长飞轮。

## Tech Stack（增量）

| 新增依赖 | 用途 |
|----------|------|
| `tauri-plugin-dialog` | 文件保存对话框 |
| OffscreenCanvas (Web API) | 图片渲染 |
| `cocoa::appkit::NSPasteboard` | 剪贴板写入 PNG |

## Commands

```bash
# 开发
npm run tauri dev

# 验证导出图片
# 手动触发分享卡片生成，检查输出 PNG 文件
```

## Functional Specifications

### FS-3.1 每日分享卡片生成

**描述**：将当前日期的日记数据渲染为一张高质量竖版 PNG 图片。

**卡片规格**：

| 属性 | 值 |
|------|-----|
| 尺寸 | 1080 x 1920 px |
| 格式 | PNG |
| 质量 | > 90% |
| 文件大小目标 | < 500KB |
| 背景 | 深色渐变 #1a1a2e -> #16213e |
| 品牌水印 | 底部 "Made with 击刻 KeyDiary" |

**卡片内容布局（从上到下）**：

1. 日期标题：如 "2026年5月25日 周日"
2. 迷你键盘热力图（精简版，保留视觉识别度）
3. 核心数据区：总击键、峰值 KPM、活跃时间、最长心流
4. 迷你 KPM 曲线（简化版面积图）
5. 最爱按键 Top 3
6. 后悔指数（Cmd+Z 次数）
7. 品牌水印

**渲染方案**：使用 OffscreenCanvas 在前端生成。

**配色方案（暗色卡片）**：

| 元素 | 颜色 |
|------|------|
| 背景渐变 | #1a1a2e -> #16213e |
| 主文字 | #e0e0e0 |
| 强调数字 | #4fd1c5（青绿色） |
| 次要文字 | rgba(255, 255, 255, 0.6) |
| 分割线 | rgba(255, 255, 255, 0.1) |

**字体**：系统字体（SF Pro Display / PingFang SC），避免字体许可问题。

**验收条件**：

- 点击后 < 2 秒内生成预览图
- 预览图视觉精美，文字清晰不模糊（1080x1920 高清）
- 卡片底部有品牌水印文字
- DPI 处理正确（考虑 devicePixelRatio）

### FS-3.2 卡片预览与导出交互

**描述**：生成卡片后弹出预览窗口，提供保存和复制选项。

**交互流程**：

1. 用户点击日记页面右上角 [生成分享卡片] 按钮
2. 收集当前日期的所有数据
3. 调用渲染引擎生成 PNG
4. 弹出模态预览窗口（显示卡片缩略图）
5. 用户选择操作：
   - [保存图片] -> 打开文件保存对话框
   - [复制到剪贴板] -> 写入系统剪贴板
   - [取消] -> 关闭预览
6. 完成后显示 toast 提示

**保存逻辑**：

| Command | 参数 | 返回 | 说明 |
|---------|------|------|------|
| `save_card_image` | `png_data: Vec<u8>` | `Result<String, String>` | 弹出保存对话框，默认文件名 "击刻-YYYYMMDD.png" |
| `copy_image_to_clipboard` | `png_data: Vec<u8>` | `Result<(), String>` | 通过 NSPasteboard 写入 PNG |

**验收条件**：

- 能保存为 PNG 文件到本地
- 能复制到剪贴板，粘贴到微信聊天框可发送
- 保存/复制后有 toast 成功提示
- 取消时无副作用

### FS-3.3 每周周报数据

**描述**：自动聚合一周的数据生成周报。

**数据结构**：

```
WeeklyReport {
    week_start: String,           // "2026-05-19"
    week_end: String,             // "2026-05-25"
    total_keystrokes: u64,        // 本周总击键
    daily_average: u64,           // 日均击键
    total_active_hours: f32,      // 总活跃时间（小时）
    most_productive_day: String,  // 最高效的一天
    most_productive_kpm: u32,     // 那天的峰值 KPM
    total_flow_minutes: u32,      // 本周心流总时长
    top_apps: Vec<AppStat>,       // 本周应用 Top 5
    daily_breakdown: Vec<DayStat>,// 7 天逐日数据
    fun_fact: String,             // 趣味文案
}
```

**触发时机**：

| 时机 | 行为 |
|------|------|
| 每周一 00:01 | 自动为上一周生成周报并存入 `weekly_reports` 表 |
| 手动触发 | 用户在周报 Tab 中查看任意历史周 |
| 通知提醒 | 周一首次打开 app 时弹出通知 |

**新增数据库表 `weekly_reports`**：

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PK AUTOINCREMENT | 主键 |
| week_start | TEXT | UNIQUE NOT NULL | 周起始日 |
| week_end | TEXT | NOT NULL | 周结束日 |
| report_json | TEXT | NOT NULL | 完整报告 JSON |
| created_at | TEXT | DEFAULT datetime('now','localtime') | 创建时间 |

**Tauri Commands**：

| Command | 参数 | 返回 |
|---------|------|------|
| `get_weekly_report` | `{ week_start: String }` | `WeeklyReport` |
| `list_available_weeks` | 无 | `Vec<{ week_start, week_end }>` |

**验收条件**：

- 周报数据聚合正确（总击键 = 7 天之和）
- 无数据的周显示"本周暂无数据"

### FS-3.4 趣味文案生成

**描述**：纯规则生成（不使用 AI），将数据转化为有趣的比喻文案。

**规则**：

| 条件 | 文案模板 |
|------|----------|
| total >= 80000 | "本周你按键 {N} 次，相当于写了 {novels} 部短篇小说！" |
| total >= 50 * 2500 | "本周你按键 {N} 次，相当于打了一本 {pages} 页的小册子。" |
| 默认 | "本周你按键 {N} 次，活跃了 {hours} 小时。" |

**验收条件**：

- 文案合理，不出现 "0 页"、"NaN" 等异常
- 数字使用千位分隔符格式化

### FS-3.5 周报卡片渲染

**描述**：将周报数据渲染为分享卡片（规格同每日卡片：1080x1920）。

**卡片内容布局**：

1. 标题："击刻周报"
2. 日期范围："2026.05.19 - 05.25"
3. 本周总击键（大字强调）
4. 趣味文案
5. 7 天柱状图（每日击键对比）
6. 本周亮点（最高效日、心流总计、最快速度）
7. 应用分布（横向百分比条）
8. 品牌水印

**验收条件**：

- 周报卡片的每日柱状图数据正确
- 7 天柱状图比例合理（最高的满格）
- 视觉风格与每日卡片统一

### FS-3.6 周报 Tab 页面

**描述**：主窗口新增 Tab 导航，周报作为独立 Tab 展示。

**Tab 导航**：

```
[ 日记 ]  [ 周报 ]
```

**周报 Tab 内容**：

- 顶部：周选择器（<- 第20周 ->）
- 中间：周报卡片预览（在 app 内直接渲染）
- 底部：[导出图片] 按钮

**交互**：

- 左右箭头切换周
- 只有有数据的周可以显示
- 导出图片流程复用 FS-3.2 的逻辑

**验收条件**：

- Tab 切换正常
- 周报 Tab 能查看本周/历史周的报告
- 导出功能正常工作

## Non-Functional Requirements

| 指标 | 目标值 |
|------|--------|
| 卡片生成时间 | < 2s |
| PNG 文件大小 | < 500KB |
| 卡片渲染清晰度 | 1080x1920，文字无锯齿 |
| 剪贴板写入 | 兼容微信/飞书/iMessage 粘贴 |

## Boundaries

**Always**：

- 品牌水印始终存在（不可关闭）
- 使用系统字体，避免字体许可问题
- 导出前显示预览，用户确认后才保存

**Ask First**：

- 修改卡片尺寸或比例
- 新增卡片模板
- 修改品牌水印内容

**Never**：

- 不上传卡片到任何服务器
- 不在卡片中包含敏感信息（按键序列等）
- 不自动分享（必须用户手动操作）

## Success Criteria

- [ ] 日记页面右上角出现"生成分享卡片"按钮
- [ ] 点击后 < 2 秒内生成预览图

- [ ] 能保存为 PNG 文件到本地
- [ ] 能复制到剪贴板并粘贴到微信发送
- [ ] 卡片底部有品牌水印
- [ ] 周报 Tab 能查看本周/历史周的报告
- [ ] 周报卡片每日柱状图数据正确
- [ ] 趣味文案合理（不出现异常值）
- [ ] 无数据的周显示"本周暂无数据"
