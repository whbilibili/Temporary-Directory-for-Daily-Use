# Spec: Phase 0 — 项目骨架与技术选型

## Objective

搭建 Tauri 2.0 项目骨架，跑通 Rust 后端到 Web 前端的通信链路，实现系统托盘驻留。这是所有后续功能的技术基座。

**目标用户**：开发者自身（单人项目）

**核心价值**：验证技术选型可行性，建立开发基础设施。

## Tech Stack

| 层级 | 选型 | 版本要求 |
|------|------|----------|
| 桌面框架 | Tauri 2.0 | `@tauri-apps/cli >= 2.0` |
| 前端框架 | Svelte 5 | 最新稳定版 |
| 构建工具 | Vite | 最新稳定版 |
| 后端语言 | Rust | stable channel |
| 数据存储 | SQLite | via `rusqlite` crate |

## Commands

```bash
# 初始化项目
npm create tauri-app@latest keydiary -- --template svelte-ts

# 安装依赖
cd keydiary && npm install

# 开发模式
npm run tauri dev

# 生产构建
npm run tauri build
```

## Functional Specifications

### FS-0.1 Tauri 项目初始化

**描述**：使用官方模板创建 Tauri 2.0 + Svelte 5 + TypeScript 项目，确保基础结构完整。

**验收条件**：
- `npm run tauri dev` 能正常启动，无编译错误
- Vite dev server 启动成功，热更新正常工作

### FS-0.2 系统托盘配置

**描述**：配置 macOS 菜单栏托盘图标，作为应用常驻入口。

**配置项**：
- 托盘图标：`icons/tray-icon.png`，设置为 template icon（适配深色/浅色菜单栏）
- 左键点击行为：显示/隐藏主窗口（非弹出菜单）

**菜单项**：

| 菜单项 | 行为 |
|--------|------|
| 打开击刻 | 显示主窗口 |
| 暂停采集 / 恢复采集 | UI 占位，Phase 1 实现逻辑 |
| 退出 | 完全退出进程 |

**验收条件**：
- macOS 菜单栏出现击刻图标
- 点击图标弹出/隐藏主窗口
- 点击"退出"菜单项能完全退出进程

### FS-0.3 窗口行为管理

**描述**：主窗口的显示/隐藏逻辑，实现"关闭即隐藏"的驻留行为。

**行为规则**：

| 操作 | 期望行为 |
|------|----------|
| App 启动 | 主窗口默认隐藏，只显示托盘图标 |
| 点击托盘图标 | 切换窗口显示/隐藏 |
| 点击窗口关闭按钮 | 隐藏窗口到托盘（不退出进程） |
| 点击"退出"菜单项 | 完全退出 |

**窗口参数**：
- 默认尺寸：800×600
- 最小尺寸：640×480
- 可调整大小：是
- 标题栏：系统原生

**验收条件**：
- 关闭窗口后 app 不退出（托盘图标仍在）
- 再次点击托盘图标能重新显示窗口

### FS-0.4 前后端通信验证

**描述**：通过 Tauri Command 机制验证 Rust ↔ Svelte 通信链路。

**接口定义**：

```
Command: get_app_status
参数：无
返回：String（如 "Hello, KeyDiary"）
```

**前端行为**：
- App.svelte 加载时调用 `invoke('get_app_status')`
- 将返回值展示在页面上

**验收条件**：
- 主窗口显示 "击刻 KeyDiary" 标题
- 页面显示从 Rust 侧返回的状态文字

### FS-0.5 SQLite 数据库初始化

**描述**：在应用首次启动时创建本地数据库文件。

**规格**：
- 数据库路径：`~/.keydiary/data.db`
- 首次启动时自动创建目录和文件
- Phase 0 只创建空数据库，不建表（表结构在 Phase 1 创建）

**验收条件**：
- App 启动后 `~/.keydiary/data.db` 文件被创建
- 文件为合法的 SQLite 数据库（可用 `sqlite3` 命令打开）

## Boundaries

**Always**：
- Rust 代码使用 `cargo fmt` + `cargo clippy` 保持整洁
- 前端代码使用 ESLint + Prettier
- 每个 commit 确保 `npm run tauri dev` 能正常启动

**Ask First**：
- 添加新的 Rust crate 依赖
- 修改 `tauri.conf.json` 的权限配置

**Never**：
- 不在 Phase 0 引入按键监听相关代码
- 不添加网络相关功能
- 不引入重量级 UI 框架

## Success Criteria

- [ ] `npm run tauri dev` 正常启动，无编译错误
- [ ] macOS 菜单栏出现击刻图标
- [ ] 点击图标能弹出主窗口
- [ ] 主窗口显示 "击刻 KeyDiary" + 从 Rust 返回的状态文字
- [ ] 关闭窗口后 app 不退出（托盘仍在）
- [ ] 点击"退出"菜单项能完全退出进程
- [ ] `~/.keydiary/data.db` 文件被创建

## Technical Risks

| 风险 | 概率 | 影响 | 缓解策略 |
|------|------|------|----------|
| Tauri 2.0 系统托盘 macOS 兼容性 | 低 | 中 | 查阅 Tauri 2.0 release notes，确认 tray API 稳定 |
| Svelte 5 + Tauri 模板版本滞后 | 低 | 低 | 可手动升级 Svelte 版本 |

## Dependencies

- 前置依赖：无（这是第一步）
- 后续被依赖：Phase 1-4 的所有功能都建立在此骨架之上
