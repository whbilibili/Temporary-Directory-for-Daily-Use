|------|------|

| **标题** | 数据库查询优化 |
| **描述** | 某些 API 查询性能不佳，需要添加索引和优化 SQL |
| **优先级** | P1 |
| **预计工作量** | 3 天 |
| **状态** | in_progress |
| **创建时间** | 2026-04-20 |
| **相关任务** | - |
| **相关文档** | ARCHITECTURE.md#性能考虑, docs/caveats.md#API响应超时 |

**详细说明**：
```
当前问题：
- GET /api/users 响应时间 > 1 秒
- GET /api/posts 响应时间 > 2 秒
- 数据库缺少必要的索引

改进方案：
1. 分析慢查询日志
2. 添加索引：
   - CREATE INDEX idx_users_status ON users(status)
   - CREATE INDEX idx_posts_user_id ON posts(user_id)
3. 优化 SQL 查询
4. 添加查询缓存

预期收益：
- API 响应时间降低 80%
- 数据库 CPU 使用率降低 50%
- 用户体验提升
```
