C. Expo / React Native App

iPhone 通知最稳，但开发、测试、分发都更重，不适合一开始就上。

我的推荐

  • 先用 A 做 MVP，尽快跑通家庭共享与滚动提醒
  • Convex 很适合处理共享状态、图片和到期计算
  • 如果后续觉得 iPhone Web Push 不够稳，再升级到 C

需要接受的现实

  • PWA 推送要求用户把网页加到 iPhone 主屏幕
  • 通知可靠性通常仍不如真正原生 App
  • 数据默认会存放在 Convex Cloud，不是纯本地
