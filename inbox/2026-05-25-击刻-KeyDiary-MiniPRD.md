## 1. 产品概述 (Product Overview)

### 产品名称

**击刻** (KeyDiary)

### 一句话定位 (Elevator Pitch)

一款隐私优先的桌面应用，将你每天的键盘使用行为自动转化为一页精美的「打字视觉日记」——不记录你打了什么，只记录你怎么打的。

### 核心价值 / 解决的痛点

现有的键盘统计工具（WhatPulse、Keyboard Metrics）只给你冷冰冰的数字："今天按了 5 万次键"。然后呢？So what？

击刻解决的核心问题是：**让打字数据"可读"、"可感"、"可分享"**。

- **可读**：不是报表，是一本每天自动生成的视觉日记，有节奏感、有故事线
- **可感**：通过心流检测、后悔指数、应用切换频率等维度，反映你的工作状态和情绪
- **可分享**：精美的日记卡片 / 周报卡片，天然适合社交传播（类似 Spotify Wrapped 效应）

### 目标用户画像

| 用户类型 | 核心需求 | 使用场景 |
|----------|----------|----------|
| 程序员 / 写作者 | 了解自己的工作节奏，量化心流时间 | 每日回顾、效率复盘 |
| 机械键盘爱好者 | 可视化自己的键位使用分布，验证布局选择 | 分享到键盘社区、对比不同布局 |
| 数据控 / 量化自我爱好者 | 长期追踪个人行为数据 | 年度报告、趋势分析 |
| 远程工作者 | 客观记录自己的工作时段和强度 | 向自己/团队证明工作投入 |

## 2. 用户旅程 (User Journey)

```
下载安装（< 10MB，无需注册）
    ↓
首次启动 → 授权输入监听权限（macOS Accessibility / Windows 管理员）
    ↓
应用退到菜单栏/系统托盘 → 静默采集开始
    ↓
正常使用电脑一整天（用户完全无感）
    ↓
当日 23:59 或用户主动点击 → 生成今日「打字日记」
    ↓
查看日记：热力图 + 心率曲线 + 会话气泡 + 今日之最
    ↓
（可选）一键导出分享卡片 → 发到社交媒体 / 机械键盘社区
    ↓
每周日生成「周报卡片」→ 查看趋势 & 解锁成就徽章
    ↓
年底生成「年度打字报告」→ 社交传播爆点
```

**核心 Aha Moment**：第一次看到自己全天的 KPM（每分钟击键数）心率曲线时，"原来我下午 3 点之后效率断崖式下跌"、"原来我 Cmd+Z 按了 312 次"——这种自我认知的震撼感。

## 3. 核心功能模块 (Core Feature Modules)

### 模块 A：静默采集引擎 (Silent Collector)

**职责**：在后台高效、低资源占用地采集键盘行为数据，绝不影响用户正常使用。

**功能点 1：按键频率采集**
- 记录每个物理键的按下次数（不记录按键序列/内容）
- 记录按键持续时长（区分轻触 vs 长按）
- 时间粒度：5 秒一个桶（bucket），用于后续曲线绘制
- 存储格式：`{timestamp, key_code, count, avg_duration_ms}`

**功能点 2：活跃应用上下文**
- 每 5 秒采样一次当前前台应用名称（如 "Visual Studio Code"、"Chrome"、"Slack"）
- 不采集窗口标题/网页 URL（隐私保护）
- 用于后续的「应用分布饼图」和「应用内击键对比」

**功能点 3：心流会话检测**
- 定义：连续打字（两次击键间隔 < 5 秒）持续 > 3 分钟 = 一个「心流会话」
- 记录每个会话的起止时间、总击键数、平均 KPM、所在应用
- 当间隔 > 30 秒时，当前会话结束

**功能点 4：快捷键组合识别**
- 识别 modifier + key 组合（Cmd+C, Ctrl+Z, Cmd+Shift+P 等）
- 统计各快捷键的使用频次
- 不记录普通连续按键序列

**性能约束**：
- CPU 占用 < 0.5%（idle 状态）
- 内存占用 < 30MB
- 磁盘写入：批量写入，每 60 秒 flush 一次到 SQLite

**隐私设计（核心原则）**：
- ❌ 绝不记录按键的顺序/序列（无法还原输入内容）
- ❌ 绝不记录密码输入框中的击键（检测 SecureTextField）
- ❌ 绝不上传任何数据到服务器
- ✅ 所有数据存储在本地 SQLite 文件中
- ✅ 用户可随时一键删除全部历史数据

---

### 模块 B：日记生成引擎 (Diary Generator)

**职责**：将当日原始数据转化为一页可视化丰富的「打字日记」。

**功能点 1：键盘热力图**
- 渲染完整键盘俯视图（支持多种布局：60%/TKL/全尺寸/分体）
- 颜色映射：按下次数 → 冷色（蓝）到暖色（红）的连续色谱
- 交互：hover 某键显示精确数字（按下 2,847 次，平均按住 45ms）
- 直觉解读：一眼区分「代码日」（分号/括号/hjkl 亮）vs「写作日」（字母均匀）vs「摸鱼日」（方向键/空格集中）

**功能点 2：心率曲线 (KPM Timeline)**
- X 轴：时间（00:00 - 23:59）
- Y 轴：每分钟击键数 (Keys Per Minute)
- 粒度：5 分钟聚合
- 区域着色：KPM > 个人平均值 1.5x 的时段标绿（心流态），< 平均值 0.3x 标灰（低活跃）
- 标注：自动标出「今日最长心流：14:05-14:48，共 43 分钟」

**功能点 3：会话气泡图**
- 每个心流会话 = 一个气泡
- 气泡大小 = 会话时长
- 气泡颜色 = 所在应用（VSCode 蓝、Chrome 红、Terminal 绿…）
- 气泡位置 = 时间轴上的起始时间
- 点击气泡展开详情

**功能点 4：今日之最 (Daily Highlights)**
- 🏆 最常用键 Top 5（带使用次数）
- ⏱ 最长心流时段（起止时间 + 时长）
- 🔢 总击键数（+ 趣味换算："相当于打了 XX 页 A4 纸"）
- ↩️ 后悔指数：Cmd+Z / Ctrl+Z / Backspace 的总次数
- ⚡ 峰值打字速度：最快的 1 分钟达到了 XX KPM
- 🔀 应用切换次数（上下文切换频率）

**功能点 5：应用时间分布**
- 环形图/饼图展示各应用的活跃打字时间占比
- 区分「有效输入时间」vs「总前台时间」

### 模块 C：回顾与趋势 (Review & Trends)

**职责**：提供周/月/年维度的聚合洞察和社交分享能力。

**功能点 1：周报卡片**
- 每周日自动生成
- 卡片式设计（竖版，适合手机屏分享）
- 内容：本周总击键、日均 KPM、最高效的一天、心流总时长、最爱快捷键
- 趣味文案："本周你按键 247,382 次，如果换成钢琴，你弹了 3 首肖邦练习曲"
- 一键导出为 PNG（带品牌水印）

**功能点 2：趋势对比**
- 折线图：近 30 天的日 KPM 均值趋势
- 柱状图：每日击键总数 + 心流时长
- 热力日历：类似 GitHub contribution graph，颜色 = 当日活跃度
- 支持对比：本周 vs 上周、本月 vs 上月

**功能点 3：成就系统**
- 🥇 心流大师：连续 7 天心流 > 30 分钟
- ⌨️ Vim 信徒：hjkl 使用次数 > 方向键
- 🚀 快捷键忍者：日均快捷键使用 > 500 次
- 🌙 夜猫子：连续 5 天凌晨仍在打字
- 📈 稳定输出：连续 30 天日击键数波动 < 20%
- 🎯 百万击键：累计击键突破 100 万次
- 解锁时有微动画庆祝，可选推送通知

**功能点 4：年度报告**
- 每年 12 月底自动生成「年度打字报告」
- 多页翻阅式设计（参考 Spotify Wrapped / GitHub Year in Review）
- 包含：年度总击键、月度变化曲线、最活跃的月/周/日、年度之最、键位偏好变迁
- 强社交属性：精美视觉设计，鼓励用户截图分享

### 模块 D：设置与个性化 (Settings & Personalization)

**功能点 1：键盘布局配置**
- 预设：QWERTY / Colemak / Dvorak / AZERTY / JIS
- 自定义：支持导入 JSON 格式的自定义布局

**功能点 2：视觉主题**

  - 🌑 赛博朋克（深色底 + 霓虹色热力）
  - ⚪ 极简黑白（灰度热力图）
  - 🌿 自然渐变（蓝绿色系）
  - 🟢 复古终端（黑底绿字 CRT 风格）
- Pro 版解锁更多主题 + 自定义颜色

**功能点 3：数据管理**
- 一键导出全部数据为 JSON / CSV
- 选择性删除：按日期范围删除
- 数据库文件位置透明可见（用户可自行备份）

**功能点 4：采集控制**
- 排除应用列表：在指定应用中暂停采集（如密码管理器）
- 工作时间设定：仅在设定时段内采集（如 9:00-22:00）
- 全局暂停/恢复快捷键

## 4. 关键技术约束 (Technical Constraints)

### 约束 1：绝对隐私优先

这是一个类似 keylogger 的工具，必须从架构层面消除用户的安全顾虑：

- 代码开源（或至少核心采集模块开源），接受社区审计
- 本地 only，零网络通信（app 本身不含任何网络请求能力）
- App Store / 公证签名，通过平台安全审核
- 首次启动时清晰展示「我们记录什么 / 不记录什么」的对比说明

### 约束 2：极致轻量

用户对"后台常驻程序"天然敏感，必须做到"无感"：

- 安装包 < 10MB
- 内存占用 < 30MB
- CPU 占用 < 0.5%（日常）/ < 2%（生成日记时短暂峰值）
- 不使用 Electron（太重），优先选择 Tauri 2.0（Rust 后端 + Web 前端）

### 约束 3：即装即用

- 无需注册/登录（没有账号体系）
- 无需联网（离线完整可用）
- 安装后唯一需要的操作：授权系统输入监听权限
- 支持 macOS 12+ 和 Windows 10+

## 5. 技术选型 (Tech Stack)

| 层级 | 选型 | 理由 |
|------|------|------|
| 桌面框架 | **Tauri 2.0** | Rust 后端保证性能/安全，Web 前端做 UI，包体积 < 10MB |
| 按键监听 | macOS: `CGEventTap`；Windows: `Raw Input API` | 系统级低延迟监听 |
| 数据存储 | **SQLite**（via rusqlite） | 单文件、嵌入式、零配置 |
| 前端框架 | **Svelte 5** | 编译时响应式，运行时零开销，适合桌面 app |
| 可视化 | **D3.js**（热力图/曲线）+ **Canvas 2D**（性能敏感区） | 灵活度高，支持精细动画 |
| 动画 | CSS Transitions + `requestAnimationFrame` | 轻量，不引入额外动画库 |
| 构建 | Vite + Rust (Cargo) | Tauri 默认工具链 |

## 7. 商业模式 (Business Model)

### 定价策略

| 版本 | 价格 | 包含功能 |
|------|------|----------|
| **Free** | ¥0 | 实时 KPM 显示、基础日击键统计、键盘热力图（当日） |
| **Pro** | ¥68 一次性买断 | 完整日记生成、历史回顾、周/月/年报告、成就系统、全部主题、数据导出 |
| **Pro+**（未来） | ¥128 | 多设备数据合并（本地 WiFi 同步）、自定义成就、API 导出 |

### 为什么选择一次性买断

- 目标用户群（开发者/极客）极度反感工具类订阅
- WhatPulse 的 $1.5/月订阅在社区口碑很差
- 参考成功案例：Raycast Pro、CleanShot X、Pixelmator Pro 都是买断制
- 大版本升级（v2.0）可以作为独立付费升级

### 收入预估（保守）

- 转化率假设：免费用户 5% 转付费
- Year 1 目标：5,000 免费用户 → 250 付费 → ¥17,000 收入
- Year 2 目标：20,000 免费用户 → 1,000 付费 → ¥68,000 收入
- 长期：通过年度报告的社交传播实现自然增长

## 9. 风险与应对 (Risks & Mitigations)
